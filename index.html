Um site, cinco temas

Esta página nunca muda de conteúdo. Clique nos temas acima e veja cores, fontes, cantos e sombras mudarem só com CSS.

O que você vai praticar

Variáveis CSS

Cada tema é um conjunto de variáveis como --fundo e --destaque. O resto do CSS só usa essas variáveis.

Seletor :has()

Quando um botão de tema está marcado, o body troca as variáveis. Nenhuma linha de JavaScript.

Tipografia

Cada tema tem um par de fontes: uma para títulos e outra para o texto corrido.

Desafio

  1. Abra o style.css e copie o bloco de um tema.
  2. Crie o seu: troque o nome, as cores e as fontes.
  3. Adicione um botão novo no index.html com o mesmo id do seu tema.
  4. Publique no GitHub Pages e envie o link.
